# Welcome to Aitho Design UI

Aitho Design UI is a React component library built with TypeScript, Radix UI
primitives and Panda CSS. It is distributed under the Apache-2.0 license.

## Getting Started

Install the package:

```bash
npm install @aitho/ui
```

`react` and `react-dom` (18 or 19) are peer dependencies and must already be
installed in the consuming project.

### Build and browser requirements

The package exposes its ESM entrypoint and TypeScript declarations through
package `exports`. Import from `@aitho/ui` using an ESM-compatible build tool,
such as Vite, that handles CSS imports. The JavaScript bundle imports the
library styles, so no separate CSS import or resolver alias is needed.

Every module is marked `"use client"`, so components can be server-rendered by
frameworks such as Next.js. `ThemeProvider` renders the light theme first and
applies the theme saved in `localStorage` after mounting.

### Wrap configuration

Mount one `<ThemeProvider>` at the application root. It applies the active
theme and brand tokens to the whole document. Nested providers and separate
brand scopes on the same page are unsupported. The light/dark preference is
saved in `localStorage` under the `theme` key.

```tsx
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";
import { ThemeProvider } from "@aitho/ui";

ReactDOM.createRoot(document.getElementById("root") as HTMLElement).render(
  <React.StrictMode>
    <ThemeProvider>
      <App />
    </ThemeProvider>
  </React.StrictMode>,
);
```

### Import example

Import the standard components from the main entrypoint:

```jsx
import { Button, Label } from "@aitho/ui";
```

## Theming

Every component reads its colors from a set of CSS custom properties
(`--color-primary`, `--text-primary`, `--background-primary`, ...), each with a
built-in light and dark value. `useTheme()` reads the active one and switches
between them:

```tsx
import { useTheme } from "@aitho/ui";

function ThemeSwitch() {
  const { theme, toggleTheme } = useTheme();

  return <button onClick={toggleTheme}>Current theme: {theme}</button>;
}
```

To ship your own brand instead of the default palette, pass a `brand` prop to
`ThemeProvider` — a `light`/`dark` pair of token overrides. Anything you don't
override keeps the library's default value:

```tsx
<ThemeProvider
  brand={{
    light: { "color-primary": "#1a73e8" },
    dark: { "color-primary": "#8ab4f8" },
  }}
>
  <App />
</ThemeProvider>
```

See the "Providers / Theme Provider" page for the full list of overridable
tokens and more examples.
